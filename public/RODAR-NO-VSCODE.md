# PRISMA13 no VS Code

Abra esta pasta `public` no VS Code.

## Rodar

1. Pressione `Ctrl+Shift+P`.
2. Escolha `Tasks: Run Task`.
3. Selecione `PRISMA13: rodar local`.
4. Abra `http://localhost:5500`.

## Depurar

Use `Run and Debug` e escolha:

- `PRISMA13: abrir no Edge`
- `PRISMA13: abrir no Chrome`

O app roda sem dependencias externas. Basta ter Node.js instalado.
